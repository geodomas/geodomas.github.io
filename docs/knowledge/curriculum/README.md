# GEODOMAS AI Curriculum v1

Machine-readable public training package for GEODOMAS technology orientation.

- `curriculum.json` — 14 ordered learning modules.
- `glossary.json` — public-safe terminology and claim boundaries.
- `qa_examples.jsonl` — supervised question/answer examples.
- `evaluation.jsonl` — evaluation prompts with required/forbidden concepts.

The curriculum is grounded in current public GEODOMAS product material, the current CALC runtime/config/contracts, and the public project-start guide. It intentionally does not contain production BOM/cutting know-how, private pricing, client data, internal prompts or unrestricted engineering conclusions.
