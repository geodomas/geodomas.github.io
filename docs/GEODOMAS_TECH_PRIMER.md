# GEODOMAS technology primer — public orientation

GEODOMAS treats a dome as a product system rather than only a shape.

Typical chain:

`purpose → product family → geometry → structural system → envelope → openings → foundation/interface → building services → documentation → production → logistics → installation → operation`

## Geometry
GEODOMAS CALC is used to configure and inspect geodesic geometry. Public tools may expose model identity, radius/diameter, frequency, sphere fraction, topology and user-supplied mesh summaries.

## Structure
Frame and connection families vary by product. A profile token or connection label is not by itself a structural certificate. Loads and final member/connection adequacy are project-specific.

## Envelope
Different product families use different envelope logic: membrane/hybrid hospitality shells, transparent aluminium-glass facades, protective PVC/glass roof shells, concrete/shotcrete shells, natural-clad residential envelopes, or dedicated immersive-system interiors.

## Project logic
The correct first question is usually not “what diameter?” but “what must this object do, where, for how many people, and under what local project requirements?”
